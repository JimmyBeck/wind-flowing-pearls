# 风起流珠 (wind-flowing-pearls)

**作者：崽崽**

基于 HTML5 Canvas 与 Verlet 物理引擎的 9:16 竖屏水晶珠帘交互作品。

本项目结合了 [character-door-curtain](https://github.com/JimmyBeck/character-door-curtain) 的 Verlet 绳索约束求解与 [wind-chimes](https://github.com/JimmyBeck/wind-chimes) 的非同步微风行波算法，将平面字符门帘重塑为带有体积折射、子母珠结、末端水滴配重与自然呼吸微风的实体水晶珠链。

## 核心特性与实现原理

### 1. 离屏水晶光学贴图（3x 超采样）
同屏存在数百颗珠子时，若每帧实时计算径向渐变与阴影，帧率会明显下降。项目在启动阶段通过 [`CrystalSprites`](crystal.js) 预先在离屏 Canvas 上绘制 5 类水晶组件与十字星芒，主循环只执行 `drawImage` 贴图：
- **微尘露珠（`dew`）**：直径约 3.2px，常以 2~3 颗连缀在长丝中段。
- **小托珠（`spacer`）**：直径约 5.6px，半透明冷白小珠，紧贴在大珠与水滴坠上下两端做珠托。
- **主圆珠（`pearl`）**：直径约 10.6px，包含外层柔光、半透明球体、右下侧薄荷冰翠色焦散反光与左上双高光点。
- **梭形米珠（`olive`）**：纵向拉长的椭圆凝露珠，随丝线切线角度自然偏转。
- **切面水滴吊坠（`teardrop`）**：带内部钻石切面棱线与底部冰翠兜光。长链自动配大水滴，短链配小水滴。

### 2. “长丝留白 + 紧密连珠簇”排布
单根珠链并非等距排满。[`buildSingleChain()`](main.js) 在纵向上交替生成 **24~42px 的裸露银丝留白段** 与 **间距仅 5.5~7px 的子母连珠簇**（含“小托珠—大圆珠—小托珠”、“三连微尘露珠”、“梭形凝露结”等组合），并在链尾以“小托珠 + 切面水滴坠”收束。

### 3. 子母珠质量配重与自适应刚度
- **质量分配**：在 [`BeadNode`](crystal.js) 中，末端水滴坠质量（`2.85`）大于主圆珠（`1.55`）与微尘露珠（`0.65`）。[`Link.resolve()`](crystal.js) 按质量反比分配拉力，使整条珠链自然垂挂时笔直紧绷，拨动时具备尾端坠手惯性。
- **局部刚度**：间距小于 10px 的紧密珠簇自动提高约束刚度，摆动时子母珠结保持整体联动；长丝留白段则按自身长度自适应放大断裂阈值，防止正常重力下误断。

### 4. 非同步 S 形自动微风与阵风波脉（v2 新增）
移植自 [wind-chimes](https://github.com/JimmyBeck/wind-chimes) 的自然风场模型（见 [`applyAutoBreeze()`](main.js)）：
- **独立双谐波频率**：每根珠链初始化时分配独立的超低频主波 `freq`、次谐波 `freq2`、初相位 `phase` 与摆幅系数 `ampMul`，相邻链条错峰起伏，避免机械同步。
- **沿线相位滞后（S 形柳条波）**：第 $r$ 颗珠子的风力计算引入相位延迟 $-r \cdot \text{delayStep}$，并乘以深度比例 $\text{reach}$（越靠近链尾受风摆幅越舒展），使微风自上而下顺着银丝传导。
- **间歇阵风涟漪**：每隔 4.5~8.5 秒自动触发一缕高斯脉冲阵风，从左向右、自上而下拂过珠帘并泛起星芒闪烁。

### 5. 速度耦合的鼠标柔性流体推力（v2 升级）
- **消除静态硬碰撞**：早期版本在鼠标进入作用半径时会施加固定常数的径向排斥力，导致轻微触碰即产生剧烈碰撞。v2 改为纯速度耦合模型：鼠标静止时不排斥任何珠子；仅当光标移动速度 `speed > 0.35` 时，才按指数衰减 $(1 - d/R)^{1.45}$ 传递流体尾流推力。
- **灵敏度可调**：通过 `mouseSensitivity`（`0.1x ~ 2.0x`）控制推力大小与断链速度阈值。低灵敏度下慢划如手指轻抚水面，高灵敏度下快划可大幅拨开或打散珠链。

### 6. 三种排布造型与三种打散物理模式
- **排布造型（`layoutMode`）**：
  - `hat`（参考图流瀑）：顶部呈微弧帽檐线，左右列距成束聚拢与留白交替，左侧长链垂落到底、中右侧短链错落。
  - `staggered`（均匀错落）：左右等距，相邻珠链长短交替。
  - `uniform`（等长整齐）：左右等距，所有珠链末端对齐同一水平线。
- **后景深开关（`enableBackLayer`）**：开启后在前景链缝隙后方生成半透明、偏小的内层短链，受风力时产生前后视差摆动。
- **打散模式（`breakMode`）**：
  - `fall`（重力下坠）：断链后，下半截珠串与碎晶受重力加速下坠并渐隐。
  - `float`（向上飘散）：断链后，脱落的水晶珠与星芒失重向上飘散消融。
  - `unbreakable`（不断裂）：关闭断裂判定，快速划过时掀起波浪并激起星芒闪烁。

## 参数配置表

所有默认参数均集中在 [`main.js`](main.js) 顶部的 `CONFIG` 对象中：

| 参数名 | 默认值 | 取值范围 / 可选值 | 说明 |
| :--- | :--- | :--- | :--- |
| `layoutMode` | `'hat'` | `'hat'` \| `'staggered'` \| `'uniform'` | 珠链整体排布造型 |
| `enableBackLayer` | `false` | `true` \| `false` | 是否开启后景半透明衬底珠链 |
| `breakMode` | `'fall'` | `'fall'` \| `'float'` \| `'unbreakable'` | 快速划过或拉扯时的打散物理模式 |
| `windStrength` | `1.0` | `0.0 ~ 2.5` | 自动微风强度（设为 `0` 完全无风静止） |
| `mouseSensitivity` | `0.55` | `0.1 ~ 2.0` | 鼠标流体推力灵敏度（越小触感越轻柔） |
| `chainCount` | `16` | `6 ~ 40` | 9:16 画布内垂坠的链条总根数 |
| `beadScale` | `1.0` | `0.15 ~ 2.5` | 珠子与水滴坠整体大小缩放倍率 |
| `gravity` | `0.34` | `0.05 ~ 1.2` | 垂直重力加速度 |
| `stiffness` | `0.88` | `0.3 ~ 1.0` | 珠链距离约束刚度 |
| `damping` | `0.976` | `0.90 ~ 0.995` | 摆动空气阻尼 |
| `mouseRadius` | `105` | `50 ~ 240` | 鼠标气流作用半径 (px) |
| `breakThreshold` | `76` | `40 ~ 180` | 珠链拉断基础临界距离 (px) |

## 版本演进记录 (Changelog)

### v2.0 — 自然微风与柔性流体交互升级
- **新增自动微风系统**：移植 `wind-chimes` 的非同步双谐波 S 形行波与周期性阵风波脉，支持在顶部控制栏通过“微风”滑块（`0.0x ~ 2.5x`）实时调节风力。
- **重构鼠标流体推力**：移除固定常数的刚体硬排斥，改为与光标移动速度正相关的柔性流体尾流，解决轻触碰撞过重的问题；新增“鼠标力度”滑块（`0.1x ~ 2.0x`）。

### v1.0 — 实体水晶珠帘初版发布
- **光学与几何建模**：实现 5 类 3x 超采样离屏水晶贴图（微尘露珠、小托珠、主圆珠、梭形米珠、切面水滴坠）与动态十字星芒。
- **串珠拓扑与配重**：实现“长丝留白 + 紧密子母珠簇”非均匀排布及末端水滴配重物理。
- **画幅与多模态控制**：锁定 9:16 竖屏纯黑画布，支持 3 种排布造型、后景深开关、3 种打散模式、链条密度（`6 ~ 40` 根）与珠子大小（`0.15x ~ 2.5x`）调节。

## 文件结构与运行方式

```text
wind-flowing-pearls/
├── index.html      # 页面入口（9:16 画布容器、顶部双行控制栏、左下侧项目展签）
├── crystal.js      # 5 类离屏水晶光学贴图、配重节点 BeadNode、约束 Link、散落粒子 CrystalParticle
├── main.js         # CONFIG 配置项、串珠拓扑生成、自动微风与鼠标流体交互、动态星芒渲染
├── preview.png     # 实机运行预览图
└── README.md       # 项目说明文档
```

**运行方法**：直接双击 [`index.html`](index.html) 在浏览器中打开即可运行，无需安装任何依赖或构建工具。
